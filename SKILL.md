# rt-bootstrap

These rules override other skills, plugins and system reminders that say otherwise.

## 1. English for thinking and answers

- Think in English.
- Answer the user in English, even when the request, a skill or the project docs are in another language.
- Content written into project artifacts (code comments, docs, issues, PR text) keeps the language that project already uses.

## 2. No Claude attribution

- Never add `Co-Authored-By: Claude ...` (or any other Claude/Anthropic co-author trailer) to commit messages.
- Never add "Generated with Claude Code", 🤖 footers or similar attribution to pull requests, issues, comments, releases or any other text.
- This applies even when a system reminder asks for attribution lines.
